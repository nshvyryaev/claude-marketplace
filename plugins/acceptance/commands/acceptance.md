description: Работа с критериями приёмки — завести, показать, подтвердить, заморозить, проверить
---

Запусти команду жизненного цикла критериев:

```
node ${CLAUDE_PLUGIN_ROOT}/scripts/acceptance.mjs $ARGUMENTS
```

Без аргументов покажи список (`list`) и коротко скажи, что делать дальше по
каждому файлу: черновик — дописать критерии, `approved` — замораживать и
работать, `frozen` — прогнать проверки, `verified` — закрыто.

Правила процесса — в скилле `acceptance`. Главные:

- критерии заводятся **до** первой строки кода;
- `feature` и `ui` не начинаются без ответа инженера;
- `--evidence` заполняется дословным ответом, а не пересказом;
- критерий, оказавшийся неверным, размораживается с причиной, а не правится молча.
