# UITransform и позиционирование нод

## Якорная точка (anchor)

Якорная точка определяет, из какой точки нода «вырастает» относительно своей позиции.

| Anchor | `[x, y]` | Описание |
|--------|----------|----------|
| Центр | `[0.5, 0.5]` | Позиция = центр ноды |
| Лево-центр | `[0, 0.5]` | Позиция = левый край ноды |
| Верх-центр | `[0.5, 1]` | Позиция = верхний край ноды |
| Низ-центр | `[0.5, 0]` | Позиция = нижний край ноды |
| Верх-лево | `[0, 1]` | Позиция = левый верхний угол |

Позиция ноды задаётся относительно **якорной точки родителя** (не края родителя!).

## ⚠️ КРИТИЧНО: несоответствие якорей контейнера и дочерней ноды

### Проблема

Контейнер `anchor=[0.5, 0.5]` (центр) + дочерняя нода `anchor=[0, 0.5]` (левый край) + позиция `[0, 0, 0]`:

```
Контейнер: x=0 = центр контейнера
Дочерняя:  x=0 = левый край ноды совпадает с центром контейнера
→ Нода сдвинута вправо на половину ширины контейнера!
```

### Решение

Если дочерняя нода с anchor=[0, ...] должна быть выровнена по левому краю контейнера:
```
child.x = -(containerWidth / 2)
```

Пример: контейнер 640px, anchor=(0.5,0.5), дочерняя anchor=(0, 0.5):
```json
"position": [-320, 0, 0]
```

### Общая формула

```
child.x = -(containerWidth * containerAnchorX) + desiredLeftOffset
```

Для кнопки вплотную к левому краю контейнера 640px:
- `child.x = -(640 * 0.5) + 0 = -320`

Для кнопки с отступом 20px от левого края:
- `child.x = -(640 * 0.5) + 20 = -300`

## Порядок нод в иерархии = Z-порядок отрисовки

**⚠️ КРИТИЧНО**: ноды, идущие **ПЕРВЫМИ** в массиве `_children`, отрисовываются **НИЖЕ** (под) последующими.

```
_children: [background, content, overlay]
→ background рисуется первым (позади)
→ overlay рисуется последним (поверх всего)
```

### Практические последствия

Если нужно, чтобы LanguageSettings отображался **поверх** ClickBlocker и SleepBlocker:
```json
"_children": [ClickBlocker, SleepBlocker, LanguageSettings, ...]
                ↑ фон                        ↑ содержимое поверх фона
```

В spec JSON используй `"insertAt": "after:SleepBlocker"` вместо `"first"`.

### insertAt в add-prefab-nodes.js

| Значение | Поведение |
|----------|-----------|
| `"first"` | Вставить в начало (рисуется снизу) |
| `"last"` | Вставить в конец (рисуется сверху) |
| `"after:<name>"` | Вставить после ноды с именем `<name>` |

## Координатная система

- Ось Y направлена **вверх** (как в математике, не как в CSS)
- y=0 обычно = центр или нижний край родителя (зависит от якоря)
- Для Settings: root anchor=(0.5, 0), height=915 → верхний край панели = y=915

## Размер ноды в режиме Layout CONTAINER

При `resizeMode=1` (CONTAINER) размер ноды UITransform может не совпадать с фактическим размером — Layout пересчитает его. Задавай размер в spec как ориентировочный, Cocos пересчитает сам.
