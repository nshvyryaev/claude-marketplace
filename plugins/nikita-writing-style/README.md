# nikita-writing-style

Скилл `nikita-writing-style` — стиль делового письма Никиты Швыряева: длина и форма реплик,
пунктуация, тон, лексика, отличия площадок (MR, Jira, чаты) и маркеры ИИ-текста,
которых надо избегать.

Загружается только по явной просьбе «напиши/ответь в моем стиле». Правило
публикации не меняет: текст отдается черновиком.

```
claude plugin install nikita-writing-style@nshvyryaev-claude-marketplace --scope user
```
