# project-toolkit

Два скилла общих правил для всех проектов.

`project-toolkit` — карта общих инструментов: критерии приёмки (`acceptance`),
проверки в браузере (`verify-web`), аналитика (`analytics-kit`),
A/B-эксперименты (`ab-kit`), деплой и хостинг через единый учёт
`E:\projects\infra`.

`hosting-request` — как попросить сессию администратора сервера
(`E:\projects\infra`) развернуть приложение, выдать порт или домен, и что
сказать инженеру, если эта сессия не запущена.

Включается глобально, для всех проектов:

```
claude plugin install project-toolkit@nshvyryaev-claude-marketplace --scope user
```

Скиллы ничего не делают сами — они указывают на готовый инструмент или на того,
кто отвечает, чтобы агент в новом проекте не изобретал своё. Новый общий
инструмент — новый раздел в `skills/project-toolkit/SKILL.md`.
