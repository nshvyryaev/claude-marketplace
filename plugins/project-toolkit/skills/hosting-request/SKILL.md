# Запрос администратору сервера

Боевой машиной `cheerful-gardener` занимается отдельная сессия Claude в
`E:\projects\infra`. Она выдаёт порты и поддомены, считает, хватит ли памяти и
диска, ставит вхосты и сертификаты, следит, чтобы одно приложение не ломало
другое, и ведёт учёт. Машина маленькая (1 vCPU, ~2 ГБ на всех), поэтому её
ресурсы распределяет она одна, а не каждый проект для себя.

## Что делать самому, а что — через администратора

**Через администратора** — всё, что меняет размещение:

- новое приложение, новая служба, стенд;
- порт, поддомен, вхост, маршрут nginx, сертификат;
- `docker-compose.yml` на сервере: лимиты памяти, тома, сети, состав служб;
- таймеры, бэкапы, каталоги на машине, места для секретов;
- всё, что может задеть соседей: рост памяти или диска, тяжёлые фоновые задачи.

**Самому можно:**

- читать учёт — `E:\projects\infra\servers\cheerful-gardener.md`,
  `E:\projects\infra\apps\<приложение>.md`;
- обычный передеплой уже принятого приложения его собственной командой из
  `apps/<приложение>.md`, если меняется только код, а размещение (compose,
  лимиты, порты, маршруты, таймеры) — нет;
- осматривать машину по SSH только на чтение.

Порт «наугад», правка вхоста руками, запись на машину мимо деплоя — нельзя:
именно так одно приложение и ломает другое.

## Как отправить запрос

1. Подготовить запрос по образцу `E:\projects\infra\docs\requests.md`
   (прочитать файл и заполнить: службы с памятью и лимитом, хранилище, бэкапы,
   маршруты, имена секретов, команда деплоя). Без чисел запрос не примут.
2. Закоммитить в своём репозитории то, что администратор будет разворачивать:
   деплоится закоммиченный `HEAD`.
3. Найти сессию администратора: `ListAgents` (если инструмент не загружен —
   `ToolSearch` с запросом `select:ListAgents,SendMessage`). Нужна сессия,
   чьё имя начинается с `infra-` — имя складывается из папки проекта и
   номера, например `infra-44`. Строка `This session is …` в выводе — имя
   *вашей* сессии.
4. Отправить: `SendMessage({ to: "<имя infra-сессии>", message: "<запрос>" })`.
   В первой строке запроса указать имя своей сессии и путь к репозиторию —
   по нему придёт ответ.
5. Ждать ответа: он придёт сообщением сам, опрашивать не нужно. Пока ждёте —
   не делать серверную часть самому; работу в своём репозитории продолжать
   можно.

Нашлось несколько сессий `infra-*` — писать той, что `idle`, а при сомнении
спросить инженера.

## Если сессии администратора нет

Не делать работу на сервере вместо неё. Остановиться и сказать инженеру:

> Чтобы <что нужно>, нужна сессия администратора сервера, а она не запущена.
> Запустите её в новом терминале:
>
> ```
> cd E:\projects\infra
> claude
> ```
>
> и скажите мне продолжить — я отправлю ей запрос.

Запрос при этом подготовить заранее и показать инженеру, чтобы после запуска
отправить его без задержки. Когда инженер скажет продолжать — снова
`ListAgents` и отправка.
